Shepherd Markdown | MD Reader
=============================

A fast, offline reader for Markdown (.md) files on Windows.

Getting started
---------------
1. Open Shepherd MD from the Start menu.
2. Click "Open folder" and point it at a folder of notes.
   (Or right-click any .md file > Open with > Shepherd MD.)

Features
--------
- Tabs and tab groups, a starred library, history and saved sessions
- Full Markdown: tables, task lists, code highlighting, Mermaid diagrams,
  GitHub-style callouts
- Search across every file in your opened folders
- 5 themes plus Auto (light, sepia, silver, true dark, warm dark)
- Save as Markdown / HTML / PDF, and screenshots

Privacy
-------
Everything runs locally on your PC. Nothing is uploaded anywhere and it
works with no internet connection.

Uninstall
---------
Settings > Apps > Installed apps > Shepherd MD.
